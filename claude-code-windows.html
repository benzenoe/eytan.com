Step 1 of 7
Install Windows Terminal
✓ Done

Windows Terminal is the modern terminal app from Microsoft — way better than the old Command Prompt. On Windows 11 you probably already have it. If not, search "Windows Terminal" in the Microsoft Store and click Install.

💡 Already have it? Skip straight to Step 2. Open Windows Terminal and check — if you see a tab with PowerShell, you're good.
🐧
Step 2 of 7
Enable WSL2 (Windows Subsystem for Linux)
✓ Done

WSL2 gives you a full Linux environment inside Windows — no dual booting, no virtual machines. Open Windows Terminal as Administrator (right-click the taskbar icon → Run as administrator), then run:

● PowerShell — Run as Administrator 
wsl --install

This installs WSL2 and Ubuntu automatically. Restart your computer when prompted.

⚠️ The restart is required. After rebooting, Ubuntu will open and ask you to create a Linux username + password. Pick anything — it's just for your Linux environment.
📂
Step 3 of 7
Open Ubuntu in Windows Terminal
✓ Done

Open Windows Terminal and click the ↓ arrow next to the + tab button. You should see Ubuntu in the dropdown — click it. You're now inside Linux!

All remaining commands go in this Ubuntu tab — not PowerShell.

💡 Want Ubuntu as your default tab? Settings → Startup → Default profile → Ubuntu. Saves a click every time.
⬡
Step 4 of 7
Install Node.js via NVM
✓ Done

Claude Code needs Node.js v18+. The cleanest way to install it on Linux is with NVM (Node Version Manager). Run this in your Ubuntu tab:

● Ubuntu Terminal 
# Install NVM
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

Close the Ubuntu tab and open a new one (this loads NVM into your session). Then:

● Ubuntu Terminal — new tab 
nvm install --lts
node --version   # Should print v20.x.x or higher
💡 If nvm says "command not found", run source ~/.bashrc and try again.
📦
Step 5 of 7
Install Claude Code
✓ Done

One command — that's it:

● Ubuntu Terminal 
npm install -g @anthropic-ai/claude-code

The -g flag installs it globally so you can run claude from any folder. Takes ~30 seconds. Confirm it worked:

● Ubuntu Terminal 
claude --version   # Should print 1.x.x
🔑
Step 6 of 7
Log In to Claude
✓ Done

Launch Claude Code for the first time:

● Ubuntu Terminal 
claude

It'll open a browser window to authenticate. You have two options:

✅ Claude Pro/Max subscription (recommended if you already pay for claude.ai) — just log in with your account. No separate API key needed.
🔑 API key — get one at console.anthropic.com. Pay-as-you-go, very cheap for personal use (pennies per session).

Follow the prompts in the terminal and browser. Once done you'll land at the Claude Code prompt — a blinking cursor waiting for your first question.

🚀
Step 7 of 7
Navigate to Your Project & Start!
✓ Done

Claude Code works best when you start it from your project folder. Your Windows files are accessible at /mnt/c/ inside Ubuntu:

● Ubuntu Terminal 
# Go to your project (replace with your actual path)
cd /mnt/c/Users/Claudio/Documents/my-project

# Launch Claude Code
claude

Now just describe what you need in plain English:

🔧 Something broke?

Click any error to see the fix.

❌ "wsl: command not found" ▼
Make sure you're running PowerShell as Administrator. Right-click Windows Terminal in the taskbar → Run as administrator. Then try wsl --install again.
❌ "nvm: command not found" after installing NVM ▼
Close the Ubuntu tab completely, open a new one, and try again. If it still fails, run source ~/.bashrc in the new tab, then retry nvm install --lts.
❌ "claude: command not found" after npm install ▼
npm's global bin folder might not be in your PATH. Run: export PATH="$(npm config get prefix)/bin:$PATH" then add that same line to the end of your ~/.bashrc file so it persists.
❌ Browser doesn't open for authentication ▼
Copy the URL printed in the terminal and paste it manually into Chrome or Edge. Make sure you're already logged into claude.ai in that browser first.
❌ WSL won't start after rebooting ▼
Open PowerShell as Administrator and run: wsl --update then wsl --set-default-version 2. Then try launching Ubuntu from Windows Terminal again.
❌ I can't find my Windows files inside Ubuntu ▼
Your entire C: drive is mounted at /mnt/c/ inside Ubuntu. So C:\Users\Claudio\Documents becomes /mnt/c/Users/Claudio/Documents. Use cd /mnt/c/Users/Claudio to get there.
⚡ Quick Reference

Commands you'll use every day.

● Cheat sheet 
# ── Start Claude Code ──────────────────────────────
claude                          # Start session in current folder
claude "your question here"        # One-shot question, no session
claude --help                   # See all options

# ── Navigate to your project ───────────────────────
cd /mnt/c/Users/Claudio/Projects/my-app
claude                          # Now it knows your whole project

# ── Useful keyboard shortcuts ──────────────────────
Ctrl + C                        # Exit Claude Code
Ctrl + D                        # End input (same as exit)
↑ / ↓                           # Browse command history

# ── Keep Claude Code up to date ────────────────────
npm update -g @anthropic-ai/claude-code
claude --version               # Check current version
