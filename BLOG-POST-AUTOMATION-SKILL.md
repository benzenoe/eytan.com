```
- Color palette: Deep blues (#2c3e50), purple accents (#667eea), white highlights
- Professional and sophisticated feel

- Wide format (16:9 aspect ratio)
- No text overlays (text will be added separately)

Subject matter: [DESCRIBE THE CORE VISUAL CONCEPT]

Mood: Authoritative, forward-thinking, data-driven

Additional elements to consider:
- Subtle geometric patterns or data visualization elements
- Aerial or elevated perspective when applicable
- Clean lines and modern architecture if relevant
- Abstract representations of concepts work well

DO NOT include:
- Cheesy stock photo aesthetics
- Clip art or cartoon styles
- Busy or cluttered compositions
- Generic business handshakes or pointing at charts
```

## SEO Metadata Guidelines

### Title Tag (50-60 characters)
Format: `[Topic]: [Benefit/Hook] - Eytan Benzeno`

### Meta Description (150-160 characters)
Format: `[Hook that creates curiosity]. [What reader will learn]. [Credibility signal].`

- Primary topic keywords

## Publishing Workflow

### Step 1: Content Creation
1. Draft post following the template above
2. Include at least 3-5 data points with sources
3. Add personal experience/credibility section
4. Include actionable takeaways for each audience segment

### Step 2: Hero Image
1. Generate image using the prompt template
2. Save as: `[timestamp]-[slug-descriptor].png`
3. Upload to: `https://eytan.com/images/blog/`

### Step 3: Admin Panel Entry
1. Go to: `https://eytan.com/admin-editor.html`
2. **General Tab**: Set slug, date, author, image URL, tags, hashtags
3. **English Tab**: Enter title, excerpt, content, and all SEO fields
4. **French Tab**: Use "Translate All" or translate individual fields

### Step 4: Review & Publish
1. Preview the post
2. Verify all SEO fields are populated
3. Save as draft or publish
4. Verify static HTML pages generated (EN + FR)
5. Check sitemap updated
